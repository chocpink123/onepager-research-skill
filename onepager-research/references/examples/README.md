# Example: Lumi AI Skincare Buddy

`Lumi_AI_Skincare_Buddy_onepager.html` is a complete reference implementation of the one-pager research workflow.

Use it to study:

- bilingual Chinese / English content with synchronized claims and table headers;
- a vertically scrolling, Feishu-ready HTML layout;
- market comparison with equal dimensions across Indonesia and Brazil;
- creator pricing split by follower tier, platform, content format, and USD display;
- source links collected in a separate, visible source line;
- competitor list followed by a core feature comparison table;
- a short opportunity quote placed directly below the feature comparison;
- differentiation framed as conversational onboarding, AI skin analysis, routine continuity, proactive skin-condition follow-up, and dynamic adjustment;
- technology dependencies, fallback providers, privacy consent, and non-medical guidance notes;
- collapsed appendix logic for supporting market evidence.

This is a reference artifact, not a universal copy deck. Re-check all market numbers, exchange rates, creator benchmarks, app activity, and product claims for the new project and date.
